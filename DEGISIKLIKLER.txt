KADASTRO360 WEB PILOT v1.5.2

TKGM REGRESYON DÜZELTMESİ
- İl seçildikten sonra ilçe yüklenirken görülen ham HTTP 404 hatası giderildi.
- Gerçek ilId / ilceId / mahalleId alanları fid ve objectid alanlarından önce seçilir.
- TKGM v3.1, v3 ve v2 yedekleri artık aynı istekte yarışmaz; kaynak sırası sabit ve tutarlıdır.
- Seçilen ilin kaynak bilgisi ilçeye, ilçenin kaynak bilgisi mahalleye, mahallenin kaynak bilgisi parsel sorgusuna taşınır.
- Eski TKGM servislerindeki çift slash idari yolları güvenli yedek olarak desteklenir.
- Yeni POST uçları eklendi: /api/idari/ilceler, /api/idari/mahalleler, /api/parsel-sorgu.
- Eski GET uçları geriye uyumluluk için korunur.
- İl → ilçe → mahalle → parsel akışı mock TKGM sunucusuyla uçtan uca test edilir.

PAKET TEMİZLİĞİ
- Boş data klasörü ZIP paketinden çıkarıldı.
- Render geçici veritabanı yolu /tmp/kadastro360-data olarak ayarlandı.
- package-lock.json yalnızca registry.npmjs.org adresini kullanır.
- Node.js 22.16.0 sabitlenmiştir.
