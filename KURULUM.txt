KADASTRO360 WEB PILOT v1.9.0

YEREL KURULUM
1. Node.js 22 kurun.
2. Klasörde terminal açın.
3. npm ci
4. TEST_USERNAME, TEST_PASSWORD, SESSION_SECRET ve ADMIN_PANEL_PIN değişkenlerini ayarlayın.
5. npm run check
6. npm start

RENDER GÜNCELLEME
1. ZIP'i bilgisayarınızda açın.
2. ZIP içindeki bütün dosyaları mevcut GitHub deponuzun ana dizinine yükleyin.
3. Eski dosyaların üzerine yazılmasını kabul edin.
4. GitHub'da Commit changes yapın.
5. Mevcut Render servisinde Auto-Deploy'u bekleyin veya Manual Deploy → Deploy latest commit kullanın.
6. Yeni servis/Blueprint oluşturmayın; DNS ve domain ayarlarını değiştirmeyin.
7. Dağıtım tamamlanınca `/api/health` sonucunda version değerinin 1.9.0 olduğunu kontrol edin.

YÖNETİCİ GÜVENLİĞİ — ZORUNLU YENİ AYAR
Render → servis → Environment bölümünde yeni değişken oluşturun:
ADMIN_PANEL_PIN=yalnızca_sizin_bildiğiniz_uzun_ve_farklı_bir_kod

- Bu kod TEST_PASSWORD ile aynı olmamalıdır.
- En az 10-12 karakter; harf, sayı ve işaret içermesi önerilir.
- Yönetici girişi: https://SİTE-ADRESİ/yonetim-giris
- Normal kullanıcı girişi yönetici panelini açmaz.
- Yönetici yetkisi 30 dakika sonra yeniden doğrulanır.
- Gelen talepler yönetim panelindeki “Gelen erişim talepleri” tablosunda görünür.

AÇIK VERİ HIZLI KULLANIM
- Önce “Hazır Katmanları Getir” kullanın. Bu işlem katalog/CSV taramasını beklemez.
- Katmanı “Haritaya Ekle” ile açın.
- Ek rayiç/dosya kaynakları gerekiyorsa ayrıca “Ek Kaynakları Tara” düğmesine basın.
- WMS karoları 256 piksel ve düşük tamponla yüklenir; harita hareketi sırasında gereksiz istekler azaltılmıştır.

GÜVENLİK
- TEST_PASSWORD güçlü ve yeni bir parola olmalıdır.
- SESSION_SECRET uzun ve rastgele olmalıdır.
- ADMIN_PANEL_PIN bu ikisinden farklı tutulmalıdır.
- Şifreleri GitHub'a veya ekran görüntülerine koymayın.

VERİ KLASÖRÜ
- ZIP içinde node_modules ve data klasörü bulunmaz.
- Render Free ortamında /tmp/kadastro360-data geçicidir; yeniden deploy/uyku sonrası kullanıcılar ve erişim talepleri silinebilir.
- Kalıcı pilot kullanıcılar için ileride kalıcı PostgreSQL veya ücretli persistent disk gereklidir.

KONTROL
`npm run check` şunları doğrular:
- Sunucu ve tarayıcı JavaScript sözdizimi
- Korumalı yönetici oturumu ve erişim talebi deposu
- Hızlı açık veri kataloğu ve 256 px WMS karo önbelleği
- TKGM il → ilçe → mahalle → parsel regresyonu
- Dört hedefli çoklu rota ve yedek sağlayıcı
- Hızlı toplu yakın yer ve önbellek
- Kırsal parsel 30 km kategori genişletmesi
- İlçe merkezi önceliği ve ATM fallback
- Çok renkli ortak rota ve çakışmayan etiketler
