KADASTRO360 WEB PILOT v1.7.0

YEREL KURULUM
1. Node.js 22 kurun.
2. Klasörde terminal açın.
3. npm ci
4. TEST_USERNAME, TEST_PASSWORD ve SESSION_SECRET değişkenlerini ayarlayın.
5. npm run check
6. npm start

RENDER GÜNCELLEME
- ZIP içeriğini GitHub deposunun ana dizinine yükleyin.
- Eski dosyaların üzerine yazılmasına izin verin.
- Özellikle server.js, index.html, tkgm-client.js, package.json, package-lock.json ve render.yaml değişmelidir.
- Render > Blueprint > Manual sync çalıştırın.
- Dağıtım tamamlanınca /api/health sonucunda version değerinin 1.7.0 olduğunu kontrol edin.
- TEST_PASSWORD için güçlü ve yeni bir parola belirleyin.
- SESSION_SECRET uzun ve rastgele olmalıdır.

VERİ KLASÖRÜ
- ZIP içinde boş data klasörü bulunmaz.
- Uygulama ihtiyaç duyduğunda veritabanı klasörünü kendisi oluşturur.
- Render test ortamında /tmp/kadastro360-data kullanılır; servis yeniden kurulursa geçmiş sıfırlanabilir.
- Kalıcı kullanıcı/geçmiş için ileride Persistent Disk veya PostgreSQL kullanılmalıdır.

KONTROL
- npm run check komutu hem statik testleri hem TKGM il → ilçe → mahalle → parsel regresyon testini çalıştırır.
- Başarılı sonuçta statik/açık veri, TKGM regresyonu ve yol rotası için üç ayrı “doğrulama geçti” mesajı görülür.

YOL ROTASI
- Pilot varsayılanı: ROUTING_BASE_URL=https://router.project-osrm.org
- Üretimde bu değer kendi OSRM sunucusuna yönlendirilebilir.
